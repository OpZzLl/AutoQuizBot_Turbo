# 🤖 Auto Quiz Bot Turbo

**เจ้าของไฟล์: Kimmy**

Chrome Extension สำหรับทดลอง AI-assisted browser automation โดยใช้ Gemini API วิเคราะห์คำถามแบบตัวเลือก แล้วช่วยจัดการการเลือกคำตอบบนหน้าเว็บ

> โปรเจกต์นี้จัดทำเพื่อการเรียนรู้และทดสอบระบบเท่านั้น ควรใช้งานตามกฎของเว็บไซต์และสถาบันที่เกี่ยวข้อง

## ความสามารถหลัก

- อ่านคำถามและตัวเลือกจากหน้าเว็บที่รองรับ
- แบ่งคำถามเป็นชุดและส่งให้ Gemini วิเคราะห์ในรูปแบบ JSON
- ช่วยเลือกคำตอบบนหน้าเว็บ พร้อมแสดงสถานะการทำงาน
- รองรับโหมด Auto-Detect, Auto-Submit และ Auto-Next
- มีระบบหยุดการทำงานและรีเซ็ตสถานะ

## 🚀 วิธีติดตั้ง

1. เปิด Chrome แล้วไปที่ `chrome://extensions/`
2. เปิด **Developer mode** (มุมบนขวา)
3. คลิก **"Load unpacked"**
4. เลือกโฟลเดอร์ `aipass-quiz-extension`
5. Extension จะปรากฏในแถบเครื่องมือ

---

## 🔑 การตั้งค่า API

1. สร้าง Gemini API key ของตนเองจาก Google AI Studio
2. ตั้งค่า key เฉพาะในเครื่อง ห้าม commit key ลง Git
3. เลือกความหน่วงและโหมดการทำงาน
4. เปิดหน้าเว็บที่มีแบบทดสอบที่รองรับ
5. ตรวจสอบคำตอบก่อนส่งทุกครั้ง

---

## ⚙️ ตัวเลือก

| ตัวเลือก | คำอธิบาย |
|---------|----------|
| ความหน่วง | เวลาระหว่างแต่ละคำถาม (1.5–6 วินาที) |
| โหมดอัตโนมัติ | เลือกคำตอบทันที |
| โหมดยืนยัน | แสดงคำตอบก่อนเลือก (เร็ว ๆ นี้) |
| ส่งอัตโนมัติ | กดส่งคำตอบหลังทำครบ |

---

## ⚠️ หมายเหตุ

- โค้ดที่เผยแพร่ไม่มี API key จริงรวมอยู่
- การเรียก Gemini API อาจมีค่าใช้จ่ายตามการใช้งาน
- ความแม่นยำขึ้นกับโมเดลและโครงสร้างหน้าเว็บ
- ใช้เพื่อการเรียนรู้และทดสอบระบบเท่านั้น
